# MetaGLens 魔搭创空间(Studio)部署说明

> 比赛要求把演示 demo 部署到 ModelScope(魔搭)创空间。
> 本目录提供两种部署方式,推荐**方案 A(静态网站)**——零构建、零依赖、最快上线。

---

## 方案 A:静态网站(推荐,最快)

魔搭创空间支持「静态网站」类型,`index.html` 即入口文件。

**我们的 `submission/site/index.html` 是完全自包含的**(报告和脚本已内嵌,含 mag/contig 双路线切换),**单独上传这一个文件即可完整演示**;其余文件供评委直接打开查看。

> **两种版本**:`submission/site/` 是参赛版(讲 AI Coding 协作开发的故事);
> `submission/site-user/` 是面向用户的版本(不提及任何 AI/skill/agent,
> 只讲产品本身)。给课题组成员/普通用户看用后者。

### 步骤

1. 打开 <https://modelscope.cn/studios> → 「创建创空间」;
2. 空间类型选择 **「静态网站(Static)」**,填名称(如 `metaglens-demo`)、描述、license;
3. 创建后进入仓库页,上传 `submission/site/` 下所有文件(或至少 `index.html`);
4. 点击 **「上线」/「立即发布」**,等待部署完成;
5. 访问 `https://modelscope.cn/studios/<你的用户名>/<空间名>` 即可看到演示站。

### 说明

- 静态站里「运行」按钮显示的是**预跑记录**(页面有诚实标注),但报告、脚本、攻击面板、
  中英切换、mag/contig 路线切换全部真实可交互;
- 若想上传后直接能用,请把 `index.html`、`report_*.html`、`script_*.txt` 一起传(保持同目录),
  缺失时页面会自动回退到内嵌内容,不影响演示。

## 方案 B:Docker(实时运行版,可选)

想给评委「现场点运行、9 秒跑完」的实时体验,用 Docker 类型。

### 步骤

1. 创建创空间时选择 **「Docker」** 类型;
2. 克隆空间仓库(`git clone https://modelscope.cn/studios/<你的用户名>/<空间名>.git`);
3. 把本目录的 `Dockerfile` 放入空间仓库根目录,并把以下文件/目录一并放入:

   ```
   Dockerfile
   pyproject.toml
   README.md
   metaglens/          # 源码(含 templates 等 package-data)
   ```

4. `git add -A && git commit && git push` —— 魔搭自动构建镜像并部署;
5. 构建完成后访问空间地址,即可实时点「运行」。

### 说明

- 镜像监听 `0.0.0.0:7860`(魔搭规定端口,8080 被平台占用);
- 演示站是**只读接口 + 有界演示队列**:桩工具跑在临时目录、跑完即清、队列限流,
  不写任何用户文件、不执行任意命令;
- 演示用**桩工具 + 合成数据,不产生科学结果**(页面显著标注);
- 修改演示内容后重新 push 即可,镜像自动重建。

## 常见问题

| 问题 | 处理 |
|---|---|
| 部署后页面空白 | 确认上传了 `index.html`(静态类型入口必须叫这个名字) |
| 想换 logo | 替换 `metaglens/templates/report_logo.b64` 后重新导出/构建 |
| 构建超时 | Docker 镜像很小(纯 Python + 无科学工具),一般 3–5 分钟;若超时重试一次 |
| 空间链接打不开 | 检查是否点了「上线」,以及空间是否设为公开 |

## 评审时建议的动线(1 分钟)

1. **首屏**:项目是什么 + 为什么存在(共享服务器不许装计费型 agent);
2. **配置区**:看到真实表单(预填了演示值);
3. **运行**:方案 B 可现场点,9 秒跑完 12 阶段;方案 A 展示预跑记录;
4. **报告**:mag/contig 下拉切换,看报告随路线变化;
5. **攻击面板**:点几个按钮,看「改科学参数被拒绝」——这是别人交不出来的安全设计;
6. **审计轨迹**:git 提交数、278 项测试、两个 AI agent 协作开发的记录。
